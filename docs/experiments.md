# 实验记录

本文件记录每次 3DGS 训练运行的可核验事实（配置、产物、指标、路径），供二级三档对照与论文实验章节使用。与 `项目阶段报告.md`（进度）、`审查记录.md`（协作）互补。

## 固定实验协议（各次运行保持一致）

| 项 | 值 |
|---|---|
| 数据集 | `nerfstudio_data`（50 张 DJI 航拍，COLMAP 稀疏重建导出，2026-09-06 转换，50/50 匹配） |
| COLMAP 结果 | `colmap_run_02/sparse/0`（50/50 注册，重投影误差 0.748px） |
| 图像分辨率 | 原 4032×3024；训练自动降采样 downscale=4（约 1008×756） |
| 方法 | Nerfstudio Splatfacto（3DGS） |
| 环境 | Conda `ns_cu128`，CUDA 12.8，torch 2.7.1+cu128，gsplat 1.4.0，nerfstudio 1.1.5 |
| 随机种子 | 42（nerfstudio 默认） |
| 训练/测试划分 | train_split_fraction=0.9（45 训练 / 5 留出测试） |
| GPU | RTX 4060 Laptop，8GB |

> **档位命名约定**：快速档=5,000 次；标准档=15,000 次（尚未运行，待补做）；高质量档=30,000 次。当前仅完成快速档与 30,000 次运行；30,000 次暂定为「高质量档 / 当前正式基线」。
